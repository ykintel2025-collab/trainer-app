# Trainer-app JO10-5

Simpele trainer-app voor één jeugdteam: aanwezigheid (wedstrijd en training), opstelling op het veld, live wissels met speelminuten, doelpunten en assists, verslag per wedstrijd en seizoensstatistiek.

- Eén bestand: `index.html`, geen build nodig.
- Spelersgegevens staan niet in deze repo. Ze staan in de database van het Claude-artifact of lokaal op het toestel.
